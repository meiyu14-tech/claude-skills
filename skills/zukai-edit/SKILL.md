# 取扱説明フロー修正スキル（/zukai-edit）

`/zukai` で作成済みのHTML取扱説明フローを修正する。

## 入力

`/zukai-edit ファイル名 "修正指示"`

- **ファイル名**：`取扱説明/` フォルダ内のHTMLファイル名（部分一致でよい。日付やフルパスは省略可）
- **修正指示**：何をどう直すかのテキスト

## 処理手順

1. `G:\マイドライブ\ObsidianVault\MyVault\幸せ貢献業\取扱説明\` からファイル名に部分一致するHTMLを探す
   - 複数該当した場合：候補を一覧で見せて選んでもらう
   - 見つからない場合：フォルダ内の全ファイル一覧を見せる
2. 該当HTMLを読み、修正指示を反映する（Editツールで該当箇所のみ修正）
3. `/zukai` のルールを維持する：
   - 7要素（目的・前提・行動・情報の流れ・バトン・成功確認・トラブル対処）を欠けさせない
   - 色分け（あなた=青・システム=緑・他の人=灰）と凡例を維持
   - 中学生でもわかる平易な日本語
4. **同じファイルに上書き保存**（ファイル名・場所は変えない）
5. SendUserFile（display: render）で修正版を送付
6. 変更点を1〜3行で報告

## 注意

- 修正前のファイルは読んでから編集する（内容を確認せず上書きしない）
- 大幅な作り直しが必要な指示の場合は、上書き前に「作り直しになりますが良いですか」と確認する
