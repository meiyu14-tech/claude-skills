# 業務フロー動画化スキル（/flow-movie）

すでにある業務フローを、**そのまま動画に変える**。新しく情報を集めない。
**フローが正本で、動画はその見せ方を変えたもの。**

## 入力

`/flow-movie` の引数：`業務フロー/` にあるフローのファイル名
引数がない場合：「どのフローを動画にしますか？」と聞き、`業務フロー/` の一覧を示す。

## 実行するもの

```
python "<Vault>/情報/AIツール・自動化/flow_movie.py" "<フローのファイル名>"
```

| 引数 | 意味 |
|:---|:---|
| （なし） | 標準。ナレーション付き・1場面最低6秒 |
| `--sec 8` | 1場面の最低秒数を変える |
| `--no-voice` | 音声なし（画面だけ） |

## 出来上がるもの

- `業務フロー/動画/<フロー名>.mp4`（1920×1080・H.264＋AAC）
- 長さの目安：**1場面あたり8〜13秒 × 場面数**（6ステップのフローで約80秒）

## 場面の作られ方

フローの構造をそのまま場面に割る。**台本を書く必要はない。**

| 場面 | フローのどこから |
|:---|:---|
| 表紙 | `<h1>` と リード文 |
| 困りごと | `.pain` のブロック（あれば） |
| 各ステップ | 表の1行（`td.no` `td.step` と、説明・効果の列） |
| 締め | `.try` のブロック（あれば） |

読み上げるのは **「番号・見出し・それで何が変わるか」**。画面に出ている説明文までは読まない（動画は読み上げより見せるほうが速いため）。

## 使うもの（すべて無料・オフライン）

| 用途 | 使うもの | 備考 |
|:---|:---|:---|
| 画面を描く | Chrome | フローの印刷と同じ方法 |
| 読み上げ | Windows標準の日本語音声「Haruka」 | **APIキー・課金は不要** |
| 動画にする | ffmpeg | 未導入なら `winget install Gyan.FFmpeg` |

## ⚠️ 必ず守ること

### 1. 社外に見せる動画は「社外向けフロー」から作る

社内向けのフローには、**サーバーの構成・内部の名前・未完了事項**が入っている。
そのまま動画にすると**そのまま外に出る**（2026-07-26に実際に発覚）。

社外に出す場合は、**社外向けのフローを1枚作ってから**動画にする。フローの `<meta name="flow-audience" content="社外">` で区別する。

**社外向けフローに入れてはいけないもの：** サーバー内のパス／内部のポート番号／リポジトリ名・アカウント名／設定ファイル名／運用の道具の名前／社内の未完了事項／限定公開のURL。**作ったら機械的に検査する。**

### 2. 出来上がった動画は、まず伊藤さんだけに渡す

**読み間違い・言い回しは、聞いてみないと分からない。** お客様に出す前に必ず確認を取る。

### 3. フローを直したら動画も作り直す

動画はフローから作られる。**フローが変われば動画は古くなる。**
CLAUDE.mdの「業務フローの自動追従」に従い、フローを作り直したら動画も作り直す。

## Claudeが使うトリガー

- 「このフローを動画にして」「説明動画を作って」「見せる用の動画にして」と言われたとき
- 新しく社外向けのフローを作り、**それを人に見せる場面**が想定されるとき（自分から提案する）

## 保存と報告

- 保存先：`業務フロー/動画/`（Vault）
- **`成果物マスター.md` に必ず記録する**（区分：公開／機密を明記）
- **壁打ち・命名・機密・動作確認・報告フォーマットは共通ルール（common-rulesスキル）に従う**
