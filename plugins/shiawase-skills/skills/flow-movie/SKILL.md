# 動画作成スキル（/flow-movie）

**構成を毎回ゼロから考えない。下の5ステップの型に当てはめるだけにする。**

## 型（これが正本。順番も名前も変えない）

| STEP | ねらい | 中身 |
|:---:|:---|:---|
| **1** | **冒頭2秒でスクロールを止める** | 一番効く動きを、いきなり見せる。止まっている画で始めない |
| **2** | **Beforeで「自分ごと化」させる** | 今の困りごと。**見た人が「それ、うちだ」と思う具体** |
| **3** | **Afterで「欲しい」を作る** | 実際に動いている画面。**ここが主役で、一番長い** |
| **4** | **機能・価格で「納得感」を与える** | できることの一覧と料金。**買ってよい理由**を与える |
| **5** | **CTAで「今すぐ」行動させる** | 次にする1つの行動だけを言う。リンク・QRを出す |

**痛み（STEP2）→ 快（STEP3）→ 行動理由（STEP4・5）**の順で組み立てる。この順番を崩さない。

## 最初の一歩：5行の構成メモ

**動画を作る前に、必ず5行のメモを書く（各STEP1行）。** これを飛ばして素材を作らない。
5行が書けないうちは、まだ何を見せるか決まっていない。

## 作り方

### 段取り

| # | 誰が | 何を |
|:---:|:---|:---|
| 1 | **Claude** | 5行の構成メモを書き、**絵コンテHTML**に起こす（下記） |
| 2 | **伊藤さん** | 絵コンテを見ながら**画面を録画**し、書いてあるファイル名で受け皿に置く |
| 3 | **Claude** | 音声・字幕・音楽を載せて**1本に編集**する |
| 4 | **伊藤さん** | 出来上がりを**確認**する |

### 絵コンテHTML（これが台本の正本）

保存先：`業務フロー/動画絵コンテ_<名前>.html`
A3縦1枚。5つのSTEPを1行ずつ、次の列で書く。

| 列 | class | 中身 |
|:---|:---|:---|
| STEP | `st` | `<b>番号</b>` ＋ 名前 |
| 秒 | `sec` | 目安の秒数 |
| 🎥 カメラ | `cam` | **伊藤さんが録画するもの**。使うファイル名を `<span class="file">01_○○.mp4</span>` で書く |
| 画面の文字 | `tel` | 字幕。**改行1行＝録画1本**に対応する |
| 読み上げ | `say` | ナレーション。`（　）`で始めると「読み上げなし」になる |
| 音楽・演出 | `note` | 人が読むためのメモ（動画には出ない） |

**1つのSTEPに録画を複数書いてよい。1本の録画＝1場面になる。**
字幕の行と読み上げの文（「。」区切り）が、上から順に割り当てられる。

### 実行するもの

```
python "<Vault>/情報/AIツール・自動化/movie_edit.py" "動画絵コンテ_<名前>.html"
```

| 引数 | 意味 |
|:---|:---|
| （なし） | 標準。音声つき |
| `--dry` | **素材の過不足だけ調べる**（録画が何本届いているか） |
| `--bgm "<ファイル>"` | 音楽を重ねる。素材フォルダに `BGM.mp3` があれば自動で使う |
| `--no-voice` | 読み上げなし |

**録画が未着のSTEPは、字幕だけの画面で作る。** 後から録画を置いて実行し直せば、その場面だけ差し替わる。**全部揃うまで待たない。**

録画の置き場所（上から順に探す）：

| 場所 | 備考 |
|:---|:---|
| `デスクトップ/Claude受け皿/公開/` | **受け皿は動画を勝手に動かさない**（対象拡張子外）。見つけたら素材フォルダへ移す |
| `業務フロー/動画/素材/<絵コンテ名>/` | 保管場所 |

### 録画が無いとき（文字だけの動画）

社内の教育用など、録画が用意できない場合は業務フローからそのまま作れる。

```
python "<Vault>/情報/AIツール・自動化/flow_movie.py" "<フローのファイル名>"
```

## 出来上がるもの

`業務フロー/動画/<名前>.mp4`（1920×1080・H.264＋AAC）
長さの目安：**60〜90秒**。90秒を超えたら読み上げを削る（画面に出ている文まで読まない）。

## 使うもの（すべて無料・オフライン）

| 用途 | 使うもの | 備考 |
|:---|:---|:---|
| 字幕・表紙を描く | Chrome | フローの印刷と同じ方法 |
| 読み上げ | Windows標準の日本語音声「Haruka」 | **APIキー・課金は不要** |
| 編集 | ffmpeg | 未導入なら `winget install Gyan.FFmpeg` |
| 音楽 | **手元に音源が無い** | 伊藤さんが用意するか、ダウンロードの承認を取る。**無断でダウンロードしない** |

## ⚠️ 必ず守ること

### 1. 録画には映ったものがそのまま外に出る

**社外に出す動画の録画は、次を必ず守ってもらう。絵コンテに毎回書く。**

| 守ること |
|:---|
| **体験版**で撮る（本番のURL・実データを映さない） |
| 現場名・会社名は**架空のもの**にする。**実在の社名・お客様名・社員名を映さない** |
| **全画面表示**にする（タブ・お気に入り・URL欄を映さない） |
| 通知を止める |
| 音は不要（無音でよい） |

**出来上がった動画は、コマを抜き出して機械的に検査する。**社名・人名・限定公開のURLが映っていないか確認してから渡す。

### 2. 社外に見せる動画は「社外向けフロー」から作る

社内向けのフローには、サーバーの構成・内部の名前・未完了事項が入っている。そのまま動画にすると外に出る（2026-07-26に実際に発覚）。
社外向けは `<meta name="flow-audience" content="社外">` で区別する。

### 3. 出来上がった動画は、まず伊藤さんだけに渡す

**読み間違い・言い回し・速さは、聞いてみないと分からない。** お客様に出す前に必ず確認を取る。

### 4. 元のフローを直したら動画も作り直す

CLAUDE.mdの「業務フローの自動追従」に従う。**フローが変われば動画は古くなる。**

### 5. 価格を勝手に書かない

STEP4は「機能・価格」だが、**料金はClaudeが決めてよいものではない。**
決まっていなければ料金には触れず「まずは無料でお試し」に寄せ、**絵コンテに「要確認」として残す。**

## Claudeが使うトリガー

- 「動画を作って」「営業用の動画にして」「説明動画にして」と言われたとき
- 社外向けのフローを新しく作り、**それを人に見せる場面**が想定されるとき（自分から提案する）
- 伊藤さんが「録画を置いた」と言ったとき → `--dry` で過不足を見てから編集する

## 保存と報告

- 絵コンテ：`業務フロー/動画絵コンテ_<名前>.html`
- 動画：`業務フロー/動画/`／素材：`業務フロー/動画/素材/<絵コンテ名>/`
- **`成果物マスター.md` に必ず記録する**（区分：公開／機密を明記）
- **壁打ち・命名・機密・動作確認・報告フォーマットは共通ルール（common-rulesスキル）に従う**
