# 企画書生成スキル（/kikaku）

新しい事業・プロジェクトを**やるかどうかを判断するための社内企画書**をMarkdownで作成する。
社外提案用の資料ではない（社外向けはこの企画書が固まってから別途作成する）。

## このスキルの狙い

一般的な企画書テンプレートでは足りない。伊藤さんの経営では**すべての判断が上位概念に立ち返る**ため、
「理念・役割・6つの価値との接続」を必須項目にして、企画段階で上位概念とのズレを検出することが核心。
繋がりを書けない企画は、その時点で見送りの判断材料になる。

## 入力

`/kikaku` の引数：企画の説明（テキスト、またはファイルパス）
引数がない場合：「どんな企画ですか？思いついたことをそのまま話してください」と聞く。

情報が足りない項目は**推測で埋める前に質問する**が、質問は最大3問まで（共通ルール項10）。
それ以上は「（推定）」付きで補完し、報告に推定箇所を明記する。

## 作成前（必須）

1. 共通ルール項0に従い、**目的・完成形・保存先の3点を提示して伊藤さんのOKを得る**
2. 共通ルール項8に従い、`プロジェクト/企画/` と `プロジェクト/プロジェクト一覧.md` に似た企画がすでに無いか確認する。あれば新規作成せず追記・改訂する

## 企画書の構成

冒頭に共通ルール項14の「この書類の使い方」ブロックを必ず置く。内容はこのスキルでは以下で固定する。

```markdown
## この書類の使い方

- **この書類は何か**：この事業・プロジェクトをやるかどうかを決めるための判断書です。
- **何のために使うか**：思いつきを「やる／やらない」の判断ができる形に変えます。上位概念（理念・役割・6つの価値）と繋がらない企画を、動き出す前に止められます。
- **誰がいつ使うか**：伊藤さんと社内メンバーが、新しい企画を思いついたとき・やるか迷ったとき・関係者に説明するときに読みます。
- **使い方**：上から順に読み、項目2〜4（理念・役割・6つの価値との接続）が埋まっているかを最初に確認します。ここが空欄または曖昧な企画は、内容が良く見えても保留にします。判断が変わったら該当項目を書き換え、更新日を追記します。承認したら「プロジェクト一覧」に登録して実行に移します。
```

その下に以下11項目を必ず全部埋める。

| # | 項目 | 書く内容 |
|:---:|---|---|
| 1 | 企画名・一言説明 | 一言説明は15文字以内。説明できないものは企画になっていない |
| 2 | **理念との接続** | 「一族の物心両面の幸せを永続させる」にどう繋がるか |
| 3 | **伊藤さんの役割との接続** | 誰のやる気に、どのやり場を提供するのか。やる気が不明な人にどう明確化の方法を提供するのか |
| 4 | **6つの価値のどれか** | 提供する価値を特定する（[[6つの価値]] を参照）。特定できないなら事業にならない |
| 5 | 誰の何の困りごとか | 顧客と課題を具体的に。「みんな」は禁止 |
| 6 | 解決の方法 | 何をどう提供するか |
| 7 | お金 | 初期費用・収益の作り方・回収時期。数字が不明なら（推定）付きで幅を出す |
| 8 | 誰がやるか | 役割権限責任を明記。実行者不在の企画は成立しない |
| 9 | 成功の判定 | いつまでに何ができていれば成功か。**観測可能な事実**で書く |
| 10 | やらない場合どうなるか | 見送る判断も同じ材料で下せるようにする |
| 11 | リスクと対処 | 3ム（無理・無駄・ムラ）の観点で事前検出する |

### 埋め方の原則

- 項目2〜4が埋まらない企画は、**「上位概念との接続が確認できていない」と明記して保留を推奨する**。良さそうに見えても押し通さない
- 「該当なし」とは書かない。不明なら（推定）付きで案を入れる
- 項目9の成功判定は「売上が上がる」ではなく「◯月末時点で契約が3件成立している」のように観測できる形にする

## 保存と報告

- 保存先：`プロジェクト/企画/YYYY-MM-DD_企画名_企画書.md`
- フォルダが無ければ作成する
- 保存後、伊藤さんに要点（項目1〜4と9）を提示し、承認するかどうかを聞く
- **承認された場合**：`プロジェクト/プロジェクト一覧.md` に追加し、必要ならTrelloに初期タスクカードを作成する（経営OS第2条）
- **保留の場合**：企画書はそのまま残し、保留理由を項目11に追記する
- 命名・機密・動作確認・報告フォーマットは共通ルール（common-rulesスキル）に従う

## 注意

- 社外提案用の資料が必要な場合は、この企画書が承認された後に別途作成する（企画書をそのまま社外に出さない）
- 個人名・金額・契約内容を含むため、**原則として機密扱い**。報告時に「機密情報を含む」と明記する
